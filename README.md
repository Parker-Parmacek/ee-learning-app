# EE Learning App

Interactive electrical engineering learning web app — a personal project by Parker Parmacek.

## Modules

- Arc Flash deep dive (six chapters + quiz + incident-energy simulator)
- Boolean algebra (gates, truth tables, interactive circuit, challenges)
- Load calculations (NEC Article 220 panel-load builder + quiz)
- Breaker coordination & transformer TCC (teaching model)
- Math Tools (fault-current, power, and voltage-drop calculators)
